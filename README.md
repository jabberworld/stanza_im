# Stanza IM

Лёгкий и быстрый десктопный **XMPP/Jabber**-клиент для Linux — основан на идеях Jabbim, Psi и немного из Gajim.
Написан на **Python 3.10+** с PyQt6 и slixmpp: занимает мало памяти, почти не тратит CPU в простое и поддерживает современные стандарты XMPP.

## Ключевые возможности

- **Удобный чат**
  - превью для картинок/аудио/видео прямо в переписке
  - поддержка тем
  - стилизация текста
  - ответы и цитаты
  - исправление сообщений
  - пересылка медиа, а также любого сообщения (или произвольно выделенного текста) своим контактам
  - удобное добавление сообщения или выделенного текста в заметки
  - реакции на сообщения
  - функция "Поделиться контактом" - отправка контакта через rosterX любому другому контакту в своем списке.
  - смена группы контакта через drag-and-drop в ростере
- **Групповые чаты (конференции)**
  - список участников с отображением ролей и аватарок
  - поддержка цветных ников
  - автодополнение ников при написании сообщения
  - уведомление при упоминании
  - поддержка приглашений
  - поддержка закладок на конференции
  - поддержка "шляп"
  - модерация сообщений
  - поддержка запроса голоса
- **Чаты "1 на 1"**
  - поддержка функции привлечения внимания
- **Звонки**
  - аудио/видеозвонки 1:1 (Jingle RTP, DTLS-SRTP)
  - групповые конференц-звонки Muji (XEP-0272)
  - Поддержка STUN/TURN
- **Файлообмен**
  - HTTP Upload (XEP-0363)
  - P2P передача файлов (SOCKS5 bytestream / IBB)
  - автоприём файлов
  - автоопределение прокси для передачи файлов.
- **История и уведомления**
  - сохранение переписки (SQLite + XEP-0313 MAM архив) с возможностью поиска и удобным отображением на календаре
  - звуковые уведомления
  - OSD-уведомления
  - значок в трее с миганием при непрочитанных
- **Присутствие и статус**
  - настройка статусов и автостатуса
  - PEP-статусы (настроение, активность, музыка, геолокация)
- **live-геолокация** - делитесь своим местоположением в реальном времени с возможностью отслеживания трека на карте.
- **Система плагинов** - возможность отключить неиспользуемые в клиенте функции.
- **Русский и английский интерфейс** — автоматическое определение языка.

Полный список поддерживаемых расширений — в [XEPs.md](XEPs.md),
детальная спецификация внутреннего устройства — в [SPEC.md](SPEC.md).

Проверка соответствия современным стандартам - в [CHECKLIST.md](CHECKLIST.md).

## Запуск

```bash
python main.py
```

## Зависимости

- **Python 3.10+**
- **PyQt6**, **PyQt6-WebEngine**, **PyQt6-Multimedia**, **PyQt6-WebChannel**
- **slixmpp**, **qasync**, **defusedxml**, **aiodns**
- Опционально, для звонков: **aiortc** (`pip install stanza-im[calls]`)
- Системные библиотеки Qt/веб-движка: `libglib-2.0`, `libGL`, `libgl1`,
  `libx11`, `libfontconfig`

В Debian 13 нужные пакеты можно установить следующей командой:

```
sudo apt-get install python3-slixmpp python3-pyqt6 python3-pyqt6.qtwebengine python3-defusedxml python3-qasync python3-aiodns python3-aiortc
```

## Тесты

- **Чат 1 на 1**:
  - Диалог: работает
  - MAM: работает
  - звонки: работают (стоит протестировать с большим числом клиентов и в разных конфигурациях)
  - "Привлечь внимание": проверил в 2 стороны на Psi. Работает с поправкой на то, что Psi не анонсирует фичу (пришлось сделать обходной путь - функция включается только после привлечения внимания со стороны Psi).
- **Чат (общие заметки)**:
  - ctrl+v с изображением и отправка через HTTP Upload - работает.
    - Обработку ошибок в случае оверквоты или сервера без поддержки HTTP Upload - не проверял. По задаче при оверквоте должен быть fallback на p2p (не проверял тоже).
  - vCard: работает.
  - публикация vCard: работает.
- **Конференции**:
  - приватные сообщения: текст ходит, остальное почти не тестировано.
  - MAM: работает. При некоторой геометрии окна бывает затык с подгрузкой истории при скролле вверх - надо добавить больше триггеров.
  - Muji: работает как аудио, так и видео. Проверял с Monocles Mod. Стоит проверить еще с DinoX.
- **Файлообмен**:
  - HTTP Upload: работает
  - P2P / P2P (SOCKS5) / P2P IBB: номинально работает в одну сторону (тестировал на боте Pegas). Требует дальнейшего тестирования.
- **Разное**:
  - Заметки: создание вручную и удаление протестировал; добавление через ситуативную кнопку и через выделение -> контекстное меню тоже работает.
- **Интерфейс**:
  - синхронизация чат/ростер по числу непрочитанных и хайлайтов, переход к хайлайтам по кнопке в чате (стиль TG) - работает. Дополнительно надо проверить синхронизацию счетчиков при использовании нескольких устройств (MDS)
