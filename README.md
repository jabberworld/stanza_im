# Stanza IM

Лёгкий и быстрый десктопный **XMPP/Jabber**-клиент для Linux — основан на идеях
Jabbim и Psi. Написан на **Python 3.10+** с PyQt6 и
slixmpp: занимает мало памяти, почти не тратит CPU в простое и поддерживает
современные стандарты XMPP.

## Ключевые возможности

- **Чаты "1 на 1"**
- **Групповые чаты (конференции)**
  - список участников с отображением ролей и аватарок
  - поддержка цветных ников
  - автодополнение ников при написании сообщения
  - уведомление при упоминании
  - поддержка приглашений
  - поддержка закладок на конференции
  - поддержка "шляп"
  - модерация сообщений
- **Удобный чат**
  - превью для картинок/аудио/видео прямо в переписке
  - поддержка тем
  - стилизация текста
  - ответы и цитаты
  - исправление сообщений
  - пересылка медиа, а также любого выделенного текста своим контактам
- **Звонки**
  - аудио/видеозвонки 1:1 (Jingle RTP, DTLS-SRTP)
  - групповые конференц-звонки Muji (XEP-0272)
  - Поддержка STUN/TURN
- **Файлообмен**
  - HTTP Upload (XEP-0363)
  - P2P передача файлов (SOCKS5 bytestream / IBB)
  - приём файлов с подтверждением
  - автоопределение прокси для передачи файлов.
- **История и уведомления**
  - сохранение переписки (SQLite + XEP-0313 MAM архив) с возможностью поиска и удобным отображением на календаре
  - OSD-уведомления
  - значок в трее с миганием при непрочитанных
- **Присутствие и статус**
  - настройка статусов и автостатуса
  - PEP-статусы (настроение, активность, музыка, геолокация)
- **live-геолокация** - делитесь своим местоположением в реальном времени с возможностью отслеживания трека на карте.
- **Русский и английский интерфейс** — автоматическое определение языка.

Полный список поддерживаемых расширений — в [XEPs.md](XEPs.md),
детальная спецификация внутреннего устройства — в [SPEC.md](SPEC.md).

## Запуск

```bash
python main.py            # или
python -m stanza_im
```

## Зависимости

- **Python 3.10+**
- **PyQt6**, **PyQt6-WebEngine**, **PyQt6-Multimedia**, **PyQt6-WebChannel**
- **slixmpp**, **qasync**, **defusedxml**, **aiodns**
- Опционально, для звонков: **aiortc** (`pip install stanza-im[calls]`)
- Системные библиотеки Qt/веб-движка: `libglib-2.0`, `libGL`, `libgl1`,
  `libx11`, `libfontconfig`
