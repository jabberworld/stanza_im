# Stanza IM

Лёгкий и быстрый десктопный **XMPP/Jabber**-клиент для Linux — продолжатель
классического Jabbim (2007–2012). Написан на **Python 3.10+** с PyQt6 и
slixmpp: занимает мало памяти, почти не тратит CPU в простое и поддерживает
современные стандарты XMPP.

## Ключевые возможности

- **Групповые чаты (конференции)** — XEP-0045 MUC: отдельные вкладки,
  список участников, приглашения (XEP-0249), `xmpp:`-адреса комнат.
- **Удобный чат** — картинка/звук/видео-превью прямо в переписке, темы
  оформления в стиле Adium, стилизация текста (XEP-0393), ответы и цитаты,
  упоминания, отправленные сообщения можно исправить (XEP-0308),
  переслать или поделиться с контекстного меню медиа.
- **Звонки** — аудио/видеозвонки 1:1 (Jingle RTP, DTLS-SRTP) и групповые
  конференц-звонки Muji (XEP-0272). Работают через STUN/TURN.
- **Файлы** — HTTP Upload (XEP-0363) и пиринговые передачи (SOCKS5
  bytestream / IBB), приём файлов с подтверждением.
- **История и уведомления** — сохранение переписки (SQLite + XEP-0313 MAM
  архив), OSD-уведомления, значок в трее с миганием непрочитанного.
- **Присутствие и статус** — настройка статусов и автодоступа, PEP-статусы
  (настроение, активность, музыка, геолокация).
- **Русский и английский интерфейс** — автоматическое определение языка.

Полный список поддерживаемых расширений — в [XEPs.md](XEPs.md),
детальная спецификация внутреннего устройства — в [SPEC.md](SPEC.md).

## Запуск

```bash
python main.py            # или
python -m stanza_im
```

## Зависимости

- **Python 3.10+**
- **PyQt6**, **PyQt6-WebEngine**, **PyQt6-Multimedia**, **PyQt6-WebChannel**
- **slixmpp**, **qasync**, **defusedxml**, **aiodns**
- Опционально, для звонков: **aiortc** (`pip install stanza-im[calls]`)
- Системные библиотеки Qt/веб-движка: `libglib-2.0`, `libGL`, `libgl1`,
  `libx11`, `libfontconfig`
